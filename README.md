# EnagageAI--AI-POWERED-STUDENT-ENGAGEMENT-PREDICTION-AND-PERSONALIZED-LEARNING-
Explainable AI-powered student engagement prediction using Bi-LSTM + Attention, SHAP, personalized recommendations, and early-warning support.

EngageAI is an AI-powered student engagement prediction and personalized learning system designed to analyze student learning activities, predict engagement levels, and support personalized learning experiences.

The system uses student academic records, assessment results, and virtual learning environment (VLE) interaction data to identify patterns in student behavior. Machine learning and deep learning techniques can help predict student engagement and identify learners who may need additional support.

The main goal of this project is to improve student learning outcomes by enabling data-driven educational decisions and personalized learning recommendations.
